# BASE Sintropia v1.3

Protótipo funcional para apoio ao trabalho do Orientador Social no SCFV.

## Arquivos principais
- `index.html` — sistema BASE Sintropia
- `style.css` — estilos do sistema
- `script.js` — funcionalidades e armazenamento local
- `portfolio.html` — página Autor & Portfólio
- `portfolio.css` — estilos do portfólio
- `assets/carlos-tavares.jpg` — foto de identificação profissional

## Novidade v1.3
Página pública de Autor & Portfólio integrada ao menu, contendo formação concluída e em andamento, atuação profissional, participação na CGA/PDM de Beberibe, Conselho Escolar da E.M.E.F. Pedro de Queiroz Ferreira, projetos digitais e socioambientais, antecedentes SALIC/PRONAC, produção técnica e acadêmica e contatos profissionais.

## Privacidade
A página pública não inclui CPF, endereço residencial, documentos pessoais, dados de saúde ou outras informações sensíveis.

## Uso
Publique todos os arquivos e a pasta `assets` no mesmo repositório. O sistema e a página de portfólio funcionam por links relativos.
